# Synthetic WebP Fixtures

Generated by `bash scripts/generate-webp-fixtures.sh` using libwebp 1.6.0's
`cwebp` and `webpmux`. These are repository-owned, deterministic 64x32 images.
RGB is `(20 + (x % 4) * 64, 20 + (y % 4) * 64, 80)`; alpha is either 255 or
`((x + y) % 4) * 64`. The animation uses the two lossless images as 100 ms frames.

Tests add ICC and EXIF RIFF chunks in memory, without linking the WebP encoder
into the test executable alongside the decoder-only library.
